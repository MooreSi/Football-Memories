# Owner decisions

Questions only the owner (Simon) can answer: what to download, how it is
named and stored, how hard the app may push Hudl, and anything about the
account.

An agent that hits one does not block and does not silently guess. It picks a
**safe provisional default** (gentler on Hudl, never removes library files),
proceeds, and writes the question here.

## Format

One file per question: `NNN-short-name.md`, NNN sequential.

```
# NNN: <question>

**Status:** open | answered YYYY-MM-DD
**Raised by:** <session/PR>, YYYY-MM-DD

## The question
## Why it matters
## Provisional default in use
## What changes if the answer differs

ANSWER:
```

Answered files stay, annotated, as the record of why the app works the way it
does.
