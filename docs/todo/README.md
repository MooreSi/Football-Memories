# docs/todo: the work

Specs and plan packs for work in flight.

- Standalone spec: `docs/todo/NNN-short-name.md` (`/new-spec`).
- Plan pack: `docs/todo/<domain>/<feature>/` with `README.md`, `SPEC.md`,
  `PROGRESS.md` and `010-`-stepped task files (`/spec`).

Packs are deleted when the work ships (`/spec done`); git history is the
archive.
